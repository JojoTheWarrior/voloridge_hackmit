# Starter datasets and connections

`starter-datasets.json` is the shared six-source catalog used by the Python
store and frontend. It draws on the local power-plant, reservoir and clinic
research, but links to the original providers. These are linked sources for
Devin to access during a mission, not preloaded or continuously synced data.
No series counts or coverage dates are invented. Provider URLs were checked
on 2026-09-20; access and coverage still need to be checked for each mission.

| Source | Starting use |
| --- | --- |
| [PUDL](https://data.catalyst.coop/) | Reported power generation and plant records |
| [Sentinel-2 / Earth Search](https://element84.com/earth-search) | Satellite imagery and cloud masks |
| [Global Water Watch](https://api.globalwaterwatch.earth/) | Reservoir surface-area histories |
| [VIIRS / EOG](https://eogdata.mines.edu/products/vnl/) | Nighttime-light composites; provider registration may be required |
| [OpenStreetMap](https://www.openstreetmap.org/about) | Mapped facilities and places; completeness varies |
| [Open-Meteo](https://open-meteo.com/en/docs/historical-weather-api) | Historical weather baselines |

`starter-ideas.json` contains nine questions actually generated by Devin in
the session recorded in that file, capped at 1 ACU. The generation request
asked only for proposals, with no research, downloads or external actions.
Questions are hypotheses, not completed or validated findings. Their order
was curated so the first three cover power plants, reservoirs and clinics.

The homepage displays three questions and their source names. Choosing one
fills the editable prompt and selects the relevant linked datasets, without
starting a mission. More ideas rotates the saved batch and preserves the draft.
There is no API call or paid session on page load or rotation. Generate and
review another batch to replace the file; retain its session provenance.

On startup, the store adds missing starters and archives the untouched older
GDELT/Yahoo/CAMS defaults from the picker. Their records remain resolvable by
historical missions. User-linked datasets are retained, and repeated startup
does not duplicate sources. The live database was backed up before the first
catalog migration to `.kingdom/before-starter-catalog.db`.
